# Frontend

Inicialmente eu comecei divindo as partes. Para cada html criado 
logo em seguida criava um css pra cada, e mais pra frente fazendo um javasc para cada um também.
para dividir meus códigos na parte de html eu utilizei uma mecânica do header(topo), section(article)(meio), footer(final)(rodapé).
com isso ficou mais facil pra designar cada parte.
ja na parte de css utilizei na maioria das vezes os comandos width e height que são os básicos para se ir mexendo
e alinhando adequadamente, utilizando os pixels(px) e as porcentagens também (%).
ja na parte de javascript eu só comecei a utilizar para parte de menu,que foi comandos e eventos para determinada coisa como
o do click para abrir o menu lateral.

Basicamente so apliquei essas estruturas e consegui adequar para cada modelo, levei em base o meu projeto feito no figma.
Depois que se faz uma página e fixa uma base de layout fica mais fácil pra adequar e só trocar alguns nomes e depois ta pronto.
